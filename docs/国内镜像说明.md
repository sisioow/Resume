# 国内镜像：Gitee Pages（推荐）

免费、国内可直接打开、不会像 OSS 默认域名那样强制下载。

## 你要做的（约 5 分钟）

### 1. 注册 / 登录 Gitee

https://gitee.com → 完成手机验证（开 Pages 通常需要）。

### 2. 新建仓库

- 仓库名建议：`Resume`（与 GitHub 一致即可）
- 可见性：**公开**
- 不要勾选「使用 Readme 初始化」（空仓库更省事）

### 3. 创建私人令牌

https://gitee.com/profile/personal_access_tokens  

- 勾选 **projects**（仓库读写）
- 生成后复制保存（只显示一次）

### 4. 写入 GitHub Secrets

https://github.com/sisioow/Resume/settings/secrets/actions  

| Name | 值 |
|------|-----|
| `GITEE_TOKEN` | 上一步的私人令牌 |
| `GITEE_OWNER` | 你的 Gitee 用户名（主页 URL 里那一段） |
| `GITEE_REPO` | `Resume` |

### 5. 触发同步

Actions → **Deploy China mirror to Gitee Pages** → **Run workflow**  

成功后会把构建产物推到 Gitee 仓库的 `gh-pages` 分支。

### 6. 开启 Gitee Pages

Gitee 仓库 → **服务** → **Gitee Pages**：

- 部署分支选 **`gh-pages`**，目录选 **`/`**
- 点 **启动** / **更新**
- 免费版有时要手动再点一次 **更新** 才会刷新

地址一般为：

`https://你的用户名.gitee.io/Resume/`

把这个地址发我，我会写进站点页脚「国内镜像」。

## 说明

| 渠道 | 用途 |
|------|------|
| GitHub Pages | 海外 |
| **Gitee Pages** | **国内预览入口** |
| 阿里云 OSS | 仅备份；默认域名会强制下载 HTML |

每次推送 GitHub `main` 会自动同步到 Gitee `gh-pages`；若页面没变，到 Gitee Pages 再点一次 **更新**。
