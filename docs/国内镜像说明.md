# 国内镜像：Gitee Pages（推荐）

免费、国内可直接打开、不会像 OSS 默认域名那样强制下载。

## 你要做的（约 5 分钟）

### 1. 注册 / 登录 Gitee

https://gitee.com → 完成手机验证（开 Pages 通常需要）。

### 2. 新建仓库

- 仓库名建议：`Resume`（与 GitHub 一致即可）
- 可见性：**公开**
- 不要勾选「使用 Readme 初始化」（空仓库更省事）

### 3. 创建私人令牌

https://gitee.com/profile/personal_access_tokens  

- 勾选 **projects**（仓库读写）
- 生成后复制保存（只显示一次）

### 4. 写入 GitHub Secrets

https://github.com/sisioow/Resume/settings/secrets/actions  

| Name | 值 |
|------|-----|
| `GITEE_TOKEN` | 私人令牌（必填，勾选 projects） |
| `GITEE_REPO` | `Resume`（可选） |
| `GITEE_OWNER` | 填 **`sisio`**（不要填 GitHub 的 sisioow）；不填也会按令牌自动识别 |

仓库请设为**公开**（锁头去掉）。你的仓库地址是 `gitee.com/sisio/Resume`。

### 5. 触发同步

Actions → **Deploy China mirror to Gitee Pages** → **Run workflow**  

成功后会把构建产物推到 Gitee 仓库的 `gh-pages` 分支。

### 6. 开启 Gitee Pages

Gitee 仓库 → **服务** → **Gitee Pages**：

- 部署分支选 **`gh-pages`**，目录选 **`/`**
- 点 **启动** / **更新**
- 免费版有时要手动再点一次 **更新** 才会刷新

地址一般为：

`https://你的用户名.gitee.io/Resume/`

把这个地址发我，我会写进站点页脚「国内镜像」。

## 说明

| 渠道 | 用途 |
|------|------|
| GitHub Pages | 海外 |
| **Gitee Pages** | **国内预览入口** |
| 阿里云 OSS | 仅备份；默认域名会强制下载 HTML |

### 常见失败：`404 not found` / exit 128

说明 GitHub 推不到 Gitee，通常是：

1. **还没建仓库**，或仓库名和 Secret 不一致  
2. **`GITEE_OWNER` 填错**（必须是 Gitee 用户名，打开 gitee.com 个人主页看 URL：`gitee.com/这里`）  
3. **令牌权限不够**（需勾选 **projects**）

流水线已支持：仓库不存在时会尝试用令牌自动创建。仍失败请对照上面三项检查 Secrets。
