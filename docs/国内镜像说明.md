# 阿里云 OSS 国内镜像说明

## 为什么打开变成下载？

使用 OSS **默认域名**（`*.oss-cn-beijing.aliyuncs.com`）访问 HTML 时，阿里云会强制加上：

```http
Content-Disposition: attachment
x-oss-force-download: true
```

这是[官方安全策略](https://help.aliyun.com/zh/oss/how-to-ensure-an-object-is-previewed-when-you-access-the-object)，**无法通过改文件元数据关闭**。  
想在浏览器里正常打开页面，必须用 **已绑定的自定义域名**（中国内地域名还需 ICP 备案）。

当前桶 `shihongwei-resume` 的同步仍可用作备份；**不要用默认 OSS 域名当作品集入口**。

## 方案 A（推荐，免备案）：Cloudflare Pages

约 3 分钟，国内多数网络可直接打开：

1. 打开 [Cloudflare Pages](https://dash.cloudflare.com/) → 注册/登录（免费）
2. **Workers & Pages** → **Create** → **Pages** → **Connect to Git** → 授权 GitHub → 选 `sisioow/Resume`
3. 构建设置：
   - Framework preset: `Vite`
   - Root directory: `site`
   - Build command: `npm run build`
   - Build output directory: `dist`
4. **Save and Deploy**，得到地址如 `https://shihongwei-resume.pages.dev`
5. 把该地址发给我，或写入 `site/src/data.ts` 的 `site.mirror`

之后每次推 `main`，Pages 会自动更新。

## 方案 B：OSS + 自己的备案域名

若已有完成备案的域名：

1. OSS 控制台 → 桶 → **域名管理** → 绑定自定义域名  
2. 在域名 DNS 添加 CNAME → `shihongwei-resume.oss-cn-beijing.aliyuncs.com`（或控制台给出的 CNAME）  
3. 用自定义域名访问即可在线预览（不再下载）
