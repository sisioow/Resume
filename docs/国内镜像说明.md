# 国内镜像说明

## 重要：Gitee Pages 已下线

Gitee 已停用 Pages，仓库「服务」菜单里**不会再出现** Gitee Pages。  
请改用下面方案做国内可预览镜像。

---

## 推荐：Cloudflare Pages（免费 · 免备案）

国内多数网络可直接打开，不会像阿里云 OSS 默认域名那样强制下载。

### 步骤（约 3 分钟）

1. 打开 https://dash.cloudflare.com/ 免费注册并登录  
2. 左侧 **Workers & Pages** → **Create** → **Pages** → **Connect to Git**  
3. 授权 GitHub，选择仓库 **`sisioow/Resume`**  
4. 构建设置填写：

| 项 | 值 |
|----|-----|
| Framework preset | Vite |
| Root directory | `site` |
| Build command | `npm run build` |
| Build output directory | `dist` |

5. **Project name** 填写：`resume-shihongwei`（决定公网域名为 `https://resume-shihongwei.pages.dev`）  
6. **Save and Deploy**，等待完成  

> Cloudflare 官方说明：`*.pages.dev` 子域名创建后**不能改名**。若要从 `resume-due.pages.dev` 换成新域名，需删除旧 Pages 项目，再按上表用新项目名重建并重新 Connect to Git。

之后每次推送 GitHub `main`，Cloudflare 会自动重新构建。
